# @enginx/formx-core 开发者文档中心

欢迎使用 `@enginx/formx-core`！这是一个 **Schema 驱动**、**可插拔**、**框架无关** 的复杂表单/单据计算运行时引擎（Cell Runtime）。它将表单交互视为一个“有向无环图的计算问题”，旨在解决复杂联动、嵌套列表聚合计算（如明细表合计）、多端逻辑复用等痛点。

为了方便开发者快速集成和使用，文档已按模块进行拆分：

## 📚 文档目录

### 1. [🚀 快速上手与集成指南 (getting-started.md)](./getting-started.md)
*   NPM / PNPM 安装与引用
*   本地分发与编译构建命令（`dist-lib`）
*   本地路径文件引用（`file:` 协议）
*   纯离线静态拷贝（包括传统 Web 环境与微信小程序）

### 2. [⚙️ 核心 API 与全量示例 (api-guide.md)](./api-guide.md)
*   Schema 元数据定义格式
*   完整包含普通联动、子表、聚合和 Batching 优化的完整集成代码实例
*   大单据性能优化与最佳实践（如精准订阅更新）

### 3. [📝 表达式引擎与公式手册 (formulas.md)](./formulas.md)
*   支持的运算符（算术、比较、逻辑、参数分隔符）
*   内置数学函数与 `IF` 条件嵌套规范
*   聚合函数 `SUM` 特殊规则与数组映射

### 4. [🔌 自定义 Store 状态库注入 (store-adapters.md)](./store-adapters.md)
*   `RuntimeStore` 控制反转（IoC）接口协议
*   **MobX 适配器**（适用于小程序/React）
*   **Vue 3 / Pinia 适配器**（深度响应式）
*   **Vuex 4 适配器**（传统单向流）

### 5. [🛡️ 核心原理与稳健性设计 (internals.md)](./internals.md)
*   Kahn 拓扑排序重算机制（DAG，解决菱形依赖毛刺）
*   最大递归熔断保护（Recursion Guard）
*   浮点数防震荡容差（Epsilon Check）
*   无效值与空数据安全回落网（Safe Fallback）

## 🛠️ 包架构关系

```
┌───────────────────────────────────────────────┐
│              Blueprint Schema                 │ (配置声明: 字段类型、校验、计算公式)
└───────────────────────┬───────────────────────┘
                        │
                        ▼
┌───────────────────────────────────────────────┐
│            RuntimeEngine (内核)               │ ◄───────┐
│   - DependencyGraph (依赖拓扑排序)             │         │
│   - Safe Evaluation (不依赖 eval 的语法解析器)   │         │
│   - Recursion & Float Guards                  │         │ 1. setValue(path, value)
└───────────────────────┬───────────────────────┘         │    (用户修改/触发事件)
                        │                                 │
                        ▼ (2. 拓扑级联计算，更新状态)       │
┌───────────────────────────────────────────────┐         │
│                 RuntimeStore                  │         │
│       (状态存储容器，支持 Vanilla/Zustand 等)   ├─────────┘
└───────────────────────┬───────────────────────┘
                        │
                        ▼ (3. 状态订阅，精准更新)
┌───────────────────────────────────────────────┐
│                UI Render Layer                │ (渲染层: React / Vue / 小程序)
└───────────────────────────────────────────────┘
```
