# 📝 表达式引擎与公式手册

`formx-core` 拥有一套自研的安全表达式解析引擎。底层在构建时将表达式转换成 **RPN (逆波兰表示法)** 抽象语法树，无需使用浏览器禁用的 `eval` 或 `new Function`，完美兼容小程序与 CSP 环境，保障性能与安全。

---

## 1. 运算符支持

表达式支持算术、比较、逻辑、参数分割等多类运算符，优先级从高到低排列如下：

| 运算符 | 符号 | 示例 | 备注 |
| :--- | :--- | :--- | :--- |
| **括号** | `( )` | `(a + b) * c` | 改变运算优先级 |
| **一元运算符** | `! - +` | `!flag` 或 `-a` | 逻辑非、负数、正数 |
| **指数运算** | `^` | `a ^ b` | 表示 $a^b$ 次幂 |
| **乘除模** | `* / %` | `a * b % 2` | 乘法、除法、取模 |
| **加减** | `+ -` | `a + b - c` | 加法、减法 |
| **比较运算符** | `> < >= <= == !=` | `a >= 100` | 比较大小和相等性，返回 Boolean |
| **逻辑与** | `&&` | `cond1 && cond2`| 当且仅当两个操作数都为真时返回真 |
| **逻辑或** | `\|\|` | `cond1 \|\| cond2`| 两个操作数中有一个为真时即返回真 |
| **参数分割符** | `,` | `Math.max(a, b, c)`| 用逗号分隔函数传参 |

---

## 2. 内置函数支持

表达式引擎内置了常用的数学和逻辑控制函数，且大部分支持**变参**（即传入任意多个参数）：

### 逻辑函数
*   **`IF(condition, trueValue, falseValue)`**
    *   **描述**：经典的条件选择分支。
    *   **示例**：`IF(score >= 60, "及格", "不及格")`
    *   **嵌套示例**：`IF(score >= 90, "优秀", IF(score >= 80, "良好", "及格"))`

### 变参数学函数
*   **`Math.max(a, b, c, ...)`**
    *   **描述**：返回传入的多个参数中的最大值，支持 2 个到任意多个参数。
    *   **示例**：`Math.max(priceA, priceB, priceC, 100)`
*   **`Math.min(a, b, c, ...)`**
    *   **描述**：返回传入的多个参数中的最小值，支持 2 个到任意多个参数。
    *   **示例**：`Math.min(discountRate, 0.8)`

### 单参数学函数
*   **`Math.round(x)`**：四舍五入。
*   **`Math.floor(x)`**：向下取整。
*   **`Math.ceil(x)`**：向上取整。
*   **`Math.abs(x)`**：取绝对值。
*   **`Math.sqrt(x)`**：取平方根。
*   **`Math.pow(base, exponent)`**：等同于 `base ^ exponent` 的指数运算。

## 3. 聚合函数 `SUM` 特殊规则

在表单中，经常需要对子表（`CARD_LIST`）中的某列数值进行累计求和。

*   **语法**：`SUM(listName.columnName)`
*   **示例**：`SUM(items.amount)`
*   **工作机制**：
    1.  引擎解析表达式时，识别到 `items.amount` 是一个针对子表的变量提取路径。
    2.  在依赖图构建中，`SUM` 会让目标字段依赖于整个 `items` 数据集和它行内的 `amount`。
    3.  运行时求值，引擎会自动抽取 `items` 列表中所有子卡片对象中的 `amount` 属性，组成一个纯数值数组（如 `[200, 150, 0]`）。
    4.  最后 `SUM` 函数接收该数组并快速执行规约求和，回填最终计算值。
